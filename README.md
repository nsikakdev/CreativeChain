# CreativeChain

A decentralized creative project tracking and artistic reward system for incentivizing creative expression on Stacks blockchain.

## Features

- Creative project tracking with complexity-based rewards
- Artist level progression system with artistic bonus multipliers
- Creative point accumulation and redemption
- Portfolio optimization with time-based penalties
- Comprehensive creative program statistics

## Smart Contract Functions

### Public Functions
- `start-creative-project` - Begin creative project
- `complete-creative-project` - Complete project and earn rewards
- `claim-creative-rewards` - Claim accumulated creative points
- `optimize-creative-portfolio` - Optimize portfolio with point investment
- `complete-portfolio-optimization` - Complete optimization process

### Read-Only Functions
- `get-project-count` - Get user's total creative projects
- `get-creative-point-balance` - Get user's creative point balance
- `get-artist-level` - Get user's artist level
- `get-creative-program-stats` - Get overall program statistics

## Reward System
- Base reward: 20 points per project
- Artist bonus: 7 points per level (max level 10)
- Optimization multiplier: 3x for portfolio optimization

## Usage

Deploy the contract to create a creative incentive system where artists can track projects, earn rewards, and optimize their creative portfolios.
